# Skills

Reusable agent skills. Each skill is self-contained in its own folder and starts with a lowercase `skill.md` file.

## Included skills

- [`storyscope`](./storyscope/skill.md): Shape reader-facing writing with structural variety, concrete agency, evidence discipline, and reader trust.
- [`unslop-ui`](./unslop-ui/skill.md): Remove generic AI-generated UI patterns while preserving the host project's design system, product intent, and interaction contracts.

## Skill layout

```text
skills/
├── README.md
├── storyscope/
│   └── skill.md
└── unslop-ui/
    ├── skill.md
    └── references/
        ├── anti-slop-checklist.md
        └── sources.md
```

These skills are editorial and engineering procedures, not detector-evasion guarantees. They do not authorize invented facts, fabricated anecdotes, broken accessibility, or arbitrary replacement of an existing product's visual system.
